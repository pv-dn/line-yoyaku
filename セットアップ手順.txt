おうちサロン予約（LINE LIFF）セットアップ手順
================================================

■ いまできていること
- スマホ向け予約画面（index.html）
- LIFF（LINE内表示）
- 予約確定 → 店舗LINEへ通知（api/reserve.js）
- 公開URL: https://line-yoyaku-ashen.vercel.app


■ あなたがやること（予約通知を有効にする）
------------------------------------------------
【A】Messaging API のトークンを取る
1. LINE Developers を開く
2. プロバイダー e-yyoosshhyy を開く
3. Messaging API チャネル「予約テスト」を開く
4. 「Messaging API」タブへ
5. 「チャネルアクセストークン（長期）」を発行してコピー

【B】店舗オーナーのユーザーIDを取る
1. スマホのLINEで、公式アカウント（予約テストと連携したもの）を友だち追加
2. このURLをLINEで開く:
   https://liff.line.me/2011846202-T1D8OMqg?setup=1
3. 画面に「店舗通知用のユーザーID」が出るのでコピー

【C】Vercel に環境変数を入れる
1. https://vercel.com/eee13/line-yoyaku を開く
2. Settings → Environment Variables
3. 次を追加（Production）
   - LINE_CHANNEL_ACCESS_TOKEN = （Aでコピーしたトークン）
   - SHOP_LINE_USER_ID = （BでコピーしたユーザーID）
   - NOTIFY_CUSTOMER = false  （お客様にも送るなら true）
4. 保存したら Redeploy（再デプロイ）

【D】動作確認
1. LINEから予約画面を開いてテスト予約
2. 店舗側のLINEに「【新規予約】」メッセージが届けば成功


■ LIFF設定（済）
------------------------------------------------
- LIFF ID: 2011846202-T1D8OMqg
- Endpoint URL: https://line-yoyaku-ashen.vercel.app

■ 公式アカウントに予約ボタンを置く
------------------------------------------------
1. LINE Official Account Manager を開く
2. トークやリッチメニューに「予約する」を追加
3. リンク先:
   https://liff.line.me/2011846202-T1D8OMqg


■ 注意
------------------------------------------------
- 通知を受け取る人は、公式アカウントを友だち追加している必要があります
- トークンやユーザーIDは公開しない（index.html には書かない）
- まだないもの: 空き枠の本格管理、スプレッドシート保存
