おうちサロン予約（LINE LIFF）セットアップ手順
================================================

■ いまできていること
- スマホ向け予約画面（index.html）がブラウザで動く
- 店舗名・メニュー・時間・定休は APP_CONFIG で差し替え可能
- LIFF ID を入れると LINE 内起動に対応（未設定ならデモモード）

■ あなたがやること（LINE側）
------------------------------------------------
1. https://developers.line.biz/ を開く
2. プロバイダーを開く
3. 「新しいチャネルを作成」→「LINEログイン」を選ぶ
4. チャネル名など必要項目を入れて作成
5. 作成したチャネルを開く → 「LIFF」タブ
6. 「追加」を押す
   - LIFFアプリ名: おうちサロン予約（任意）
   - サイズ: Full
   - Endpoint URL: 公開した予約ページのURL（例: https://xxxx.vercel.app/）
   - Scope: profile にチェック（任意）
7. 発行された LIFF ID をコピー
8. index.html の APP_CONFIG.liffId に貼り付ける

■ 公式アカウント側
------------------------------------------------
1. LINE Official Account Manager を開く
2. トークやリッチメニューに「予約する」ボタンを作る
3. リンク先に LIFF URL（https://liff.line.me/LIFFのID）を入れる

■ 公開（ネットに置く）
------------------------------------------------
予約画面は HTTPS のURLが必要です。
例:
- Vercel に index.html をアップ
- GitHub Pages にアップ

公開URLができたら、上の Endpoint URL に設定してください。

■ まだやっていないこと（次の開発）
------------------------------------------------
- 店舗への自動通知（Messaging API / メール / スプレッドシート）
- 本物の空き枠管理（ダブルブッキング防止）
- 管理者画面

まずは「LINEから予約画面が開く」までがゴールです。
